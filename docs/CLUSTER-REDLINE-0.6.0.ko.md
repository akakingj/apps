# 0.6.0: 순정 계기판 보존과 실제 UI 적용

## 검은 사각형 제거

0.5.0은 panel의 중앙에 불투명한 검은 1088×480 이미지를 그렸습니다. 제공해 주신 실차 사진처럼 순정 계기판 안쪽도 가릴 수 있었습니다.

0.6.0은 **빈 픽셀의 알파를 0으로** 그립니다. 네 모서리·좌우 빈 공간·숫자 사이의 배경으로 순정 화면이 보이며, 사각형 배경을 만들지 않습니다. 실제 게이지·문자·테두리와 점등 전의 검은 LED 칸만 불투명합니다. 따라서 빈 공간으로 순정 지도·Assist 화면도 보일 수 있습니다.

**위젯 크기** 기본값은 75%입니다. panel 1920×720에서 표시 크기는 816×360, 좌표는 (552,180)입니다. 내부 렌더링은 1088×480을 유지하고 크기만 줄여 표시합니다. 설정에서 60~100% 중 선택할 수 있습니다. 차종별 순정 눈금 위치가 달라 실제 겹침 여부를 확인하고 필요하면 65~70%로 더 줄이세요. 순정 경고의 우선순위를 앱이 보장하지는 않습니다.

## 적용된 UI

- 위쪽에 짧은 RPM 게이지, 그 아래 작은 RPM 숫자
- 가솔린 최대 7000rpm에서 14칸: 1000rpm당 두 칸
- 변속 LED와 RPM 바의 양 끝을 맞추고 칸 사이에는 얇은 구분선만 표시
- RPM 바의 흰 외곽선 제거, 현재값 표시선 유지
- 위·아래 선 중앙에 직접 그린 M 삼색 마크
- 하단 중앙에 작은 단수, 그 가까이에 짧은 토크·마력 게이지
- 설정한 변속 시점에서 RPM 숫자는 적색
- 꺼진 변속 LED는 희미한 색 없이 완전 검정

## 단수 D4 / S4

받은 단수와 기어박스의 선택 프로그램이 확인되면 D4·S4·M4 형식으로 표시합니다. P·R·N은 그대로 표시합니다. **차량의 스포츠 주행 모드만 보고 S를 붙이지 않습니다.** 기어박스 프로그램은 주행 모드와 별개입니다.

차량이 단수만 보내서 S/D가 구별되지 않으면 숫자만 표시될 수 있습니다. 이 경우 **단수 앞 문자 → D / S / M**을 직접 선택할 수 있습니다. 이 설정은 화면 표시만 바꾸며 실제 변속기를 조작하지 않습니다. 수동 선택한 문자는 기어박스가 바뀌어도 자동으로 따라가지 않습니다. **자동**으로 돌리면 수신한 프로그램을 사용합니다.

## 토크와 마력

`FES.statusActualValueTorque2.actualValueTorqueCrankshaft`의 ECU 토크를 사용합니다. 변환은 `(원시값 - 2047) × 0.5 Nm`이며 4095·65535 등 무효값은 표시하지 않습니다. 엔진 제동의 음수 토크는 0으로 표시합니다.

**마력***은 이 토크와 RPM으로 계산한 엔진 출력 추정치입니다: `Nm × RPM / 9549.2966 × 1.3596216 PS`. 별표는 계산값이라는 뜻입니다. 실측 다이노 출력·구동륜 출력이나 하이브리드 모터의 합산 출력이 아닙니다.

토크를 받지 못했거나 1.8초 넘게 오래된 경우 토크와 마력 모두 `--`로 표시합니다. 데모 숫자를 실차에 넣지 않습니다. 게이지 최대값 기본은 500Nm·300PS이며 설정에서 차량에 맞게 바꿀 수 있습니다. 최대값보다 큰 실제 값은 숫자로 유지하고 바만 끝까지 채웁니다.

## 설치와 확인

1. MGU Store에서 **Check now → 설치한 언어판의 Update**로 **0.6.0**을 받습니다. 한글·영문판 모두 같은 수정이 들어갑니다.
2. **표시 레이어 → 전면 중앙 (시험)**, **위젯 크기 → 75%**를 확인합니다.
3. 먼저 12fps로 순정 속도·RPM 눈금과의 겹침, 스포츠 해제 시 복귀를 확인합니다. 필요하면 위젯 크기를 더 줄입니다.
4. 이후 30·60fps를 선택해 비교합니다. 선택값은 요청 상한이며 실차에서 지속되는 FPS나 센서 수신 속도를 보장하지 않습니다.

차량 신호는 읽기만 하며 Assist 기능, MGU 지도 설정, 엔진·변속기·코딩을 변경하지 않습니다. 실제 차량에서 이번 투명도·크기·신호 변환을 재검증한 것은 아닙니다.

## 검증

실제 앱 렌더러에서 투명 배경·14칸·LED 검정·적색 RPM·한글 폰트·프레임 차이 재구성을 검사합니다. 표시 크기 전환, 신호 무효/만료 처리, D/S 프로그램 구분, ECU 토크 변환과 PS 계산, 실제 프로토콜의 30·60fps 요청, 설정 저장과 한글·영문 Store 빌드를 검사합니다. 미리보기 수치는 예시이며 실차 신호가 아닙니다.
