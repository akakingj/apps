# 계기판 레드라인 1.0.3

## Stop & Go 화면 유지

기존에는 100rpm 미만을 엔진 정지로 판단해 레이어를 해제했습니다. 이제 엔진 작동 샘플을 한 번 확인한 뒤 **최신 0rpm과 주행 모드 신호가 계속 들어오는 동안** 화면을 유지합니다. 실제 수신된 0을 표시하며 이전 주행 RPM을 남겨두지 않습니다. 자동 재출발은 기존 레이어에서 값만 갱신합니다.

처음 앱을 켰는데 엔진이 아직 작동한 적 없는 0rpm 상태에서는 기다립니다. 잘못된 RPM·신호 만료·렌더러 연결 해제·앱 OFF·스포츠 전용 설정에서 일반 모드 전환은 기존처럼 해제합니다. RPM과 모드만으로 자동 정지와 모든 시동 상태를 구별한다고 주장하지 않습니다. eDrive에서도 엔진 작동 후 유효한 0rpm은 유지하지만 전기모터 출력은 표시하지 않습니다.

## HUD와 클러스터 화면 통일

HUD는 클러스터의 같은 그리기 함수를 사용합니다. RPM의 파랑→하늘색→보라/분홍 계열, 고정 적색 구간, 흰 커서, RPM 수치, 단수, 토크·마력과 단위/피크가 같은 기준으로 그려집니다. 단수는 클러스터처럼 아래 중앙으로 이동하고 토크·마력이 양옆에 배치됩니다. 변속 알림 중에는 두 출력의 LED가 같은 위상으로 빨간 밝음/어두움(2Hz) 반복이며 RPM 숫자는 계속 빨강입니다. 켜지지 않은 LED는 검정입니다.

HUD 원본은 **800×353**, 클러스터 원본은 1088×480으로 비율을 맞췄습니다. 기본 75% HUD 배치는 **600×265, X100/Y8**입니다. 기존 위치/가로/세로 설정값은 유지하고 실제 출력 범위 안으로 제한합니다. 설정의 좌표 계산도 실제 HUD 크기를 사용합니다. 이전 버전보다 HUD 세로 영역이 커졌으므로 실차에서 필요하면 위치/크기를 조절하세요.

비어 있는 부분은 투명하며, 변경 영역만 전송합니다. 그림이 바뀌지 않은 상태에서는 HUD 재생성을 생략합니다. 내비 안내 때 HUD 양보, 프레임 요청 상한 20fps, native 렌더러의 점유/보호 정책은 유지합니다. 같은 슬롯의 순정 안내와 커스텀 화면을 합성하는 기능이 추가된 것은 아닙니다.

## M 표시

위·아래 표시를 공통 모듈로 교체했습니다. 밝은 파랑/짙은 파랑/빨강의 사선 블록과 채워진 은색 M에 금속 음영·가장자리 밝기를 넣었습니다. 사용자 참조의 형태를 코드로 그리며 외부 이미지나 폰트를 새로 포함하지 않습니다. 투명 경계와 작은 크기에서의 안티앨리어싱을 유지하고 한 번 그린 표시는 캐시합니다.

## 검사

- 네 프리셋과 두 출력에서 작동→60초간 신선한 0rpm→재출발을 검사했습니다. 레이어 재생성/해제 없이 0과 재시동 RPM을 전송합니다.
- 앱 OFF/신호 만료/잘못된 RPM/모드 변경/연결 재설정의 기존 차단을 검사했습니다.
- HUD와 클러스터의 동일 비율 픽셀·색상·투명도·알림 위상, 단위/기어/피크 변경 및 정확한 차분 복원을 검사합니다.
- 새 M의 채워진 실루엣·삼색·금속 음영·투명 경계·작은 크기 캐시를 검사했습니다.
- 1.0.2의 Guidance Main_Instance 설치 요청과 호환성 필터를 유지하고 양 언어 패키지를 확인합니다.

이는 호스트 검사이며 실제 G20의 자동 정차/재출발 및 HUD 가독성은 차량에서 확인해야 합니다. native parked-recovery 제안 패치는 이번 앱에 의해 자동 설치되지 않습니다.
