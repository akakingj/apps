# 계기판 레드라인 1.0.2 — 설치 시 인터페이스 생성 실패 보완

사용자 차량의 1.0.1 Store 설치가 generateSomeipInterfaces 단계에서 실패했다. 화면에는 하위 오류가 잘려 있어 모든 원인을 단정할 수 없지만, 설치 패키지에서 다음 불일치를 확인했다.

- 1.0.1 Guidance 프록시: instances = "1"
- 실제 실행 코드의 Guidance 인스턴스: "Main_Instance"

app.json에 `_instances: "Main_Instance"`를 명시했다. 기본값 1은 이 이름을 대체하지 않는다. 원본 build.py가 만드는 한국어/영어 .mgu/.tgz와 Store 템플릿에 같은 이름이 들어가는지 검사한다.

Store 및 PC 설치 경로에서 선택적 내비 신호를 유지할 조건도 보완했다. 차량 카탈로그의 `instanceIDs[Guidance]`에 Main_Instance가 있고, guidanceState getter에 유효한 ID가 있어야 한다. 인터페이스/필드/getter/이름 중 하나라도 없으면 해당 선택적 프록시만 제외한다. 다른 필수 신호를 임의로 제외하거나 숫자 인스턴스를 추측하지 않는다. 이전 v1 설치 도구에서 v2 보완으로 이동해도 중복 적용되지 않는다.

신호를 제외한 차량에서는 내비 상태를 확인할 수 없으므로 앱의 HUD가 순정에 양보하고 상태를 표시한다. 계기판 출력·HUD 게이지 그림·오류 복구 기능은 1.0.1과 동일하다. 이 버전이 새로운 한국 지도 안내 연동이나 별도 native 렌더러 패치를 설치하지는 않는다.

## 검증

- 실제 이전 설치 패키지에서 잘못된 instances=1을 확인했다.
- Store 필터와 실제 PC 설치 함수에 카탈로그 모형을 넣어 Main_Instance 존재/부재/다른 이름, getter 부재/빈 ID/정상 ID를 검사했다.
- 생성된 양 언어의 .mgu/.tgz 및 SDK 없는 Store 템플릿에서 Main_Instance/r 요청을 확인한다.
- BMW의 실제 IFConfigGenerator 및 차량 카탈로그가 이 환경에 없어 실제 차량의 인터페이스 생성 성공까지 검증하지는 못했다. 앞선 모의 검사가 누락했던 인스턴스 일치 조건을 추가한 것이다.

## 업데이트

MGU Store에서 저장소를 새로고침하고 표시 버전이 **1.0.2**인지 확인한 뒤 설치한다. 캐시된 1.0.1을 재설치하지 않는다. 1.0.2에서도 실패하면 상세 오류의 뒷부분 또는 Store 설치 로그가 필요하다. 스크린샷의 하위 오류가 잘려 있었으므로 실차 설치 성공을 확인하기 전에는 전체 해결로 단정하지 않는다.
