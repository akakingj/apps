# 0.5.0: 앞쪽 중앙 표시 시험과 30·60fps

## 이번 변경

기존에는 `map` 장면에 게이지를 그렸습니다. 같은 장면의 `z=100`은 BMW의 다른 표시 영역에 있는 지도·Assist Drive View보다 앞에 나온다는 뜻이 아닙니다.

0.5.0의 **표시 레이어 → 전면 중앙 (시험)**은 `panel:1920x720` 장면에 중앙 1088×480 이미지만 배치합니다. 위치는 (416,120)이며 주변은 투명합니다. 순정 음성 대화상자가 panel을 쓰면 양보하고, 전체 계기판을 덮는 배경이나 HUD 출력은 만들지 않습니다. 차량의 Assist 기능 자체를 끄거나 MGU 지도 설정을 변경하지 않습니다.

렌더러 문서의 panel 영역을 이용한 **실차 확인용 수정**입니다. 이 차량에서 지도·Assist 화면보다 항상 앞에 표시된다고 검증한 것은 아닙니다. 순정 화면과의 실제 순서·겹침·복귀는 아래처럼 확인해야 합니다. 렌더러의 상위 alert 레이어와 순정 화면의 우선순위는 앱이 보장하지 않습니다.

기존 지도 방식으로 돌아가려면 **표시 레이어 → 지도 영역 (기존)**을 고릅니다. 이 방식에만 `map_take_over_stock=1`이 필요합니다. 전면 중앙 모드를 위해 `panel_take_over_stock`을 켤 필요는 없습니다. 앱은 panel의 순정 콘텐츠를 빼앗지 않습니다.

## 업데이트 후 확인

1. MGU Store에서 **Check now → 설치한 언어판의 Update**로 0.5.0을 받습니다. 일반 PC 빌드도 기존 `--language ko` 방식으로 설치합니다.
2. iDrive 화면에서 계기판 레드라인 앱을 열고 **표시 레이어 → 전면 중앙 (시험)**, **계기판 갱신 속도 → 12fps**를 확인합니다.
3. 정차 상태에서 스포츠 모드로 바꾸고 지도·Assist 화면과 게이지의 겹침을 확인합니다. 일반 모드로 돌아오면 게이지가 해제되는지도 확인합니다. 렌더러의 페이드나 panel 대기 시간 때문에 복귀가 즉시는 아닐 수 있습니다.
4. 여전히 가려지면 앱 하단의 `표시 영역: panel · 상태 / 소유자`와 실제 계기판 화면을 함께 확인합니다. `shown`은 렌더러의 상태 보고이며 화면 전체가 가려지지 않았다는 보장은 아닙니다.

새 설정은 기본 panel이며 기존 RPM·엔진 프로필·갱신 속도 설정은 유지합니다. 지원되지 않는 영역/크기는 표시하지 않고, map이나 HUD로 자동 변경하지 않습니다.

## 12 / 30 / 60fps

변속 알림 LED에서 아직 켜지지 않은 칸은 희미한 색이나 광택 없이 완전 검정으로 둡니다. 기존 RPM에 따른 순차 점등은 유지하며, 켜진 칸만 색을 표시합니다.

기존 4·6·8·10·12fps에 **30·60fps**를 추가했습니다. 새 설치의 기본은 12fps이며, 저장한 속도는 그대로 사용합니다.

이 숫자는 앱과 이미지 레이어가 **요청하는 갱신 상한**입니다. 60fps를 선택해도 실제 계기판에서 60fps를 지속한다는 뜻은 아닙니다. RPM 신호 수신 빈도, CPU 처리 시간, 렌더러의 공유 전송량 제한이 적용되며, 입력값이 그대로면 프레임을 다시 그리지 않습니다. 변경 시에만 화면 차이를 전송합니다. 실제로 수신하지 않은 RPM 값을 만들어 넣지 않습니다.

먼저 12fps에서 표시 문제를 확인한 뒤 30fps, 60fps 순서로 비교하세요. 60fps 지속 출력은 실차 미검증입니다. 렌더러의 전송 제한은 이 업데이트에서 변경하지 않습니다.

## UI 시안과 검증 범위

이번 버전은 표시 영역과 갱신 속도를 바꿉니다. 대화에서 만든 토크·마력·D4/S4 배치 이미지는 디자인 시안이며 이번 실행 화면에 구현된 것은 아닙니다. 토크·마력 신호 연결도 포함하지 않습니다.

PC에서 중앙 배치, 기존 지도 모드 전환, 다른 영역으로 우회하지 않음, 스포츠 해제/오래된 신호/연결 끊김 시 정리, 30·60fps 통신 요청과 설정 저장을 검사합니다. 한글·영문 Store 빌드에도 새 설정을 반영합니다. 실제 차량의 표시 우선순위와 지속 FPS는 아직 확인하지 않았습니다.
