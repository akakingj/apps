# 계기판 레드라인 0.8.3

앱 자동 켜짐 아래 주황색 안내 첫 줄에 **MGU Store에서 클러스터 렌더러(cluster-render)를 먼저 설치**하라고 표시합니다.
최소 요구 버전은 기존과 같은 0.3.10 이상이며 0.3.11과 0.4.0도 충족합니다.
바로 아래에는 선택한 표시 레이어에 맞춰 중심 표시 영역 설정을 안내합니다.

- 지도 영역: 지도 보기(Map view) 또는 꺼짐(Off)
- 전면 중앙: 기존 꺼짐 안내 유지

## 20fps 고정

계기판 갱신 속도는 **20fps 요청 상한으로 고정**합니다. 상세설정의 갱신 속도 선택 항목은 제거했습니다.
기존에 12/30/60fps를 저장한 경우에도 무시하고 렌더러 요청과 백그라운드 주기를 20fps로 맞춥니다.
상세설정 아래에는 고정값을 읽기 전용으로 표시합니다.

실제 출력 속도는 센서 갱신 주기, CPU 처리, 변경된 이미지의 전송량, 공유 대역폭 등에 따라 낮아질 수 있습니다.
이 변경으로 전송량 제한을 올리거나 GPU용 렌더링 구조를 새로 만들지는 않았습니다.
Robertn의 게시글은 최적화로 **3fps에서 20+fps로 개선한 사례**이며 하드웨어 전체의 20fps 상한을 뜻하지 않습니다.
이후 더 높은 속도를 검증하면 앱의 고정 목표값은 다시 변경할 수 있습니다.

## 현재 설정 항목

| 기본설정 | 상세설정 |
|---|---|
| 앱 자동 켜짐 | 변속 알림 RPM |
| 차량 프리셋: 가솔린 / 디젤 / eDrive / M | 표시 레이어: 전면 중앙 / 지도 영역 |
| 표시 모드: 스포츠 모드만 / 전체 모드 | 위젯 크기 |
| 마력 단위: PS / kW | |
| 토크 단위: Nm / kgf·m | |

차량 프리셋, 실제 단위 환산, D/S/M 신호 처리와 0.8.2의 첫 프레임 전송 순서는 유지합니다.
초기 지도 슬롯 선점 지연과 Assist 가림의 해결은 실차 확인이 필요합니다.
[0.8.2의 지도 선점 경로와 범위](CLUSTER-REDLINE-0.8.2.ko.md)를 참고하세요.

한국어·영어판을 같은 버전으로 제공합니다. MGU Store에서 Check now 후 0.8.3으로 업데이트합니다.

## 확인 범위

실제 앱 진입점과 저장 설정을 이용해 예전 60fps 설정이 새 고정값을 덮지 못하는지 확인합니다.
렌더러에 전달되는 fps 값과 wire 명령, 백그라운드 50ms 주기, 설정 메뉴에서 속도 항목 제거,
두 언어의 주황색 안내·화면 배치·패키지 형식을 검사합니다.
실차에서 지속 20fps가 달성됐다는 의미는 아닙니다.
