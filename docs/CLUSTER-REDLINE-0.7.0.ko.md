# 0.7.0: 기어 문자·깜빡임 보완·게이지 확대

## 기어 문자

기존에는 DataPowerTrain2의 빈 값이 다른 신호에서 받은 단수를 지울 수 있었습니다. 두 입력을 합치고, 빈 필드는 다른 입력의 정상 단수를 지우지 않게 고쳤습니다. M1·S1·D1 직접 전달값과 D만 전달되는 선택 상태도 처리합니다. 표준 전진 단수만 수신하면 기본 D를 붙이며, 차체 스포츠 주행 모드만으로 S를 추측하지 않습니다.

S/M을 `MDrive.dataDisplayGearbox.displayProgramGearbox`로 따로 보내는 차량도 처리합니다. Store 빌드는 차량의 인터페이스 목록에 이 필드가 있을 때만 선택 권한을 포함합니다. 목록을 읽지 못하거나 필드가 없으면 제외하여 기존 RPM·단수 기능은 설치할 수 있게 합니다. 목록 내용 자체는 패키지에 넣지 않습니다. 일반 PC 설치에서는 기존 선택 인터페이스 제외 처리를 사용합니다.

자동 S/M은 실제 프로그램 신호가 들어와야 합니다. 지원하지 않는 차량에서는 **단수 앞 문자 → S / M / D**로 표시 문자를 직접 고를 수 있습니다. 수동 설정은 실제 변속기를 조작하지 않으며 프로그램 변경을 자동으로 따라가지 않습니다. 단수 자체를 받지 못했을 때 1단으로 만들어 표시하지 않습니다.

## 60fps와 깜빡임

렌더러 문서상 일반 이미지의 GPU 쓰기가 끝나지 않으면 완전한 이미지로 복구할 때까지 잠시 숨겨질 수 있습니다. 이 현상이 이번 차량의 정확한 원인이라고 실차 로그로 확정한 것은 아닙니다.

이를 줄이기 위해 다음을 반영했습니다.

- 이미지 복구 중 마지막 완성 화면을 유지하는 독점 이미지 방식 사용. 투명 배경은 유지합니다. 같은 renderer target의 아래쪽 커스텀 레이어는 정지하며 상위 alert 레이어는 유지합니다. BMW 순정 panel 콘텐츠는 빼앗지 않습니다.
- 이 앱의 정상 연속 전송을 기본 약 1MiB/s로 제한하고 렌더러가 예산을 낮추면 더 줄입니다. 최초 전체 이미지는 예외이며 이후에는 최신 상태의 차이만 전송합니다.
- 토크·단수·마력의 변경 영역을 분리해 중간 빈 공간까지 전송하는 양을 줄입니다.
- RPM·모드 신호가 만료되면 즉시 숨기되, 다시 안정된 신호를 확인하고 2초 재요청 대기를 거쳐 반복 점멸을 억제합니다. 오래된 신호의 허용 시간은 늘리지 않았습니다.
- 상태 파일에 기어 입력, 표시 변경 이력, 신호 경과 시간과 전송 대기를 기록합니다. iDrive 앱 하단에서도 최근 표시 변경과 전송 대기를 확인할 수 있습니다.

12·30·60fps 선택은 요청 상한입니다. 전송량이 크면 60을 선택해도 실제 업데이트는 줄어듭니다. 렌더러의 공유 전송량 상한이나 순정 화면의 우선순위는 변경하지 않습니다. 실제 지속 FPS와 깜빡임은 이번 차량에서 다시 확인해야 합니다.

## 크기

토크·마력 막대 폭을 170에서 200으로, 높이를 9에서 12로 키웠습니다. 글자와 수치도 조금 키웠고 중앙 단수와의 간격은 남겼습니다. 새 기본 위젯 크기는 80%입니다. 저장한 75%는 덮어쓰지 않으므로 업데이트 후 **위젯 크기 → 80%**를 직접 고르세요.

## 업데이트 후

Store에서 **Check now → 설치한 언어판 Update → 0.7.0**을 확인합니다. **전면 중앙 / 위젯 크기 80% / 우선 12 또는 30fps**로 확인한 다음 60fps를 비교하세요. 자동 S/M이 안 나오면 단수 앞 문자를 수동으로 고를 수 있습니다. 한글판·영문판 중 사용할 레드라인 하나만 자동 표시를 켜 둡니다.

계속 깜빡이면 iDrive의 레드라인 앱 화면 하단과 실제 계기판 상태를 함께 확인하면 됩니다. 표시 영역의 parked/stock, 최근 변경의 rpm_unknown/mode_unknown, 전송 대기를 구분하기 위한 정보입니다.

## 검증 범위

PC에서 기어 입력 합치기·선택 프로그램·직접 M1/S1/D1·빈 입력 처리, 고속 입력 시 전송량 제한, 큰 변경 프레임의 복구, 만료 시 즉시 해제와 안정 후 재요청, 실제 프로토콜 플래그, 한글·영문 렌더링과 Store 빌드를 검사합니다. 실제 차량의 자동 S/M 수신과 깜빡임 해소는 미검증입니다.
