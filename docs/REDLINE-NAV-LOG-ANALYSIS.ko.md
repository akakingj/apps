# 1.0.6 길안내 로그 분석

실제 1.0.6 로그에서 Android Auto 안내 활성과 세 getter의 읽기 성공을 확인했습니다. 차단 이유는 `navigation_maneuver_unknown` / `maneuver_unsupported`입니다. 받은 안내 종류를 앱이 지원하지 않아 합성이 실패했고, 해당 HUD 출력만 중지해 순정에 양보했습니다. 사용자의 앱 켜짐/레드라인 선택은 모두 켜져 있습니다. 계기판 map 영역은 표시 중이며 렌더러 0.4.2의 HUD 양보 설정도 정상입니다.

원본 로그에는 실제 안내 종류 이름이 없습니다. 도로 따라가기·차로 변경·도착 안내를 스키마에 맞춰 추가하고 상태의 `maneuver.kind`에 수신 종류 이름을 기록하도록 소스를 수정했습니다. 이 셋 중 실제 원인이 어느 것인지는 확정하지 못했습니다. 방향이 없는 안내나 알 수 없는 종류를 임의로 직진 화살표로 표시하지 않습니다. 실차 해결 확인은 남아 있습니다.

RPM 색상은 2500rpm 경계를 연속으로 만들고, 2500~3500rpm 구간에서 약하게 시작해 보라색이 되도록 조절했습니다. 이후 프리셋 최대값까지 분홍·빨강으로 변하며 가솔린은 7000rpm에서 빨강입니다. 계기판과 HUD에 같이 적용됩니다.

관련 디코더·실제 worker 모의·색상·출력·앱 제어·Stop&Go 검사를 통과했습니다. 미리보기에서 새 안내와 HUD RPM 영역의 동시 표시도 검사했습니다. 앱 빌드·버전 변경·GitHub 푸시·스토어 배포는 하지 않았습니다.
