# 계기판 레드라인 0.8.4: 실행 버전 확인

설정 화면 위에 실행 중인 앱의 **v0.8.4** 배지를 표시합니다.
한국어·영어판 모두 앱을 열면 바로 **기본설정 / 상세설정** 탭을 표시합니다.
MGU GPU 렌더러를 사용하는 화면과 소프트웨어 화면에 모두 버전을 표시합니다.

이 버전은 차량에서 보고된 이전 화면과 최신 실행 화면을 구분하기 위한 업데이트입니다.
설치된 차량의 버전·소스 정보는 아직 확인하지 못했으므로, 구버전이 실행된 원인을
스토어 캐시나 특정 설치 오류로 확정하지 않습니다.
렌더러, 지도 슬롯 처리와 계기판의 20fps 요청 설정은 그대로입니다.

## 이전 화면이 계속 보일 때

보고된 화면은 상태 카드, 하단 **설정** 버튼, **30fps** 표시가 있는 이전 화면입니다.
최신 소스의 시작 화면은 상태 카드가 아니라 기본설정 탭입니다.
저장된 예전 30/60fps 설정만으로 새 앱의 시작 화면이 이전 화면으로 돌아가지는 않습니다.

1. MGU Store → Sources에서 `jaimeen77-cmyk/apps`의 **main 브랜치**를 확인합니다.
2. **Check now** 후 원하는 언어판의 사용 가능 버전이 **0.8.4**인지 확인합니다.
3. 해당 항목에서 **Update / Install**을 완료합니다. 재시작 대기 안내가 있다면 재시작을 완료합니다.
4. 앱 목록에서 방금 설치한 언어판을 직접 엽니다. 화면의 **v0.8.4**와 두 탭을 확인합니다.

같은 앱을 다른 소스나 언어판으로 설치하면 별도 항목이 생길 수 있습니다.
기존 설정을 보존하기 위해 먼저 삭제하지 말고, Store 상세 화면에서 **출처·설치 버전·사용 가능 버전**을 확인하세요.
0.8.4로 표시되는데도 이전 화면이면 이 세 정보가 보이는 Store 상세 화면과 실제 앱 화면을 함께 확인해야 합니다.

`UPDATE_FAILED; the previous version was kept`라면 설치가 실패해 이전 코드가 실행될 수 있습니다.
[설치 오류 로그 수집 방법](REDLINE-INSTALL-FAILED.ko.md)으로 원인을 확인합니다.

## 용량 확인

스토어는 이 저장소의 UI/공통 런타임 템플릿에 현재 앱 JavaScript를 넣어 패키지를 만듭니다.
템플릿에는 차량의 SDK나 cluster-render 바이너리를 넣지 않습니다.
공유 SDK 연결과 렌더러 선행 설치는 설치 관리자가 처리합니다.

이 작업에서 만든 0.8.4 파일의 실제 크기입니다. MB는 1,000,000바이트 기준입니다.

| 파일 | 압축 파일 | 압축 해제 |
|---|---:|---:|
| 한국어 스토어 패키지 | 1.11MB | 2.31MB |
| 영어 스토어 패키지 | 0.90MB | 1.93MB |
| 한국어 개인용 PC 빌드(SDK 포함) | 1.33MB | 3.76MB |

한글 글꼴 파일은 압축 전 755,507바이트로 한국어 앱에서 가장 큽니다.
따라서 **64MB를 이 앱 패키지의 실제 크기로 확인한 것은 아닙니다.**
실제 앱 파일, 저장소 다운로드, 설치 후 디스크 사용량, 실행 메모리는 서로 다른 값입니다.
64MB가 표시된 화면의 항목명을 확인해야 그 의미를 판단할 수 있습니다.

## 검증 범위

스토어가 만드는 실제 한국어·영어 패키지에서 시작 파일을 실행해 바로 설정이 그려지는지,
두 탭이 동작하는지, 화면의 버전과 패키지 버전이 일치하는지 검사합니다.
차량 신호와 백그라운드 계기판 출력은 이 검사에서 연결하지 않습니다.
PC 검사가 차량의 업데이트 완료를 확인해 주지는 않습니다.
