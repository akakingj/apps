# 계기판 레드라인1.0.5 — 길안내 신호 갱신 수정

1.0.4의 실제 worker로 다음 두 오류를 재현하고 수정했습니다.

- ACTIVE/제공자 값이 바뀌지 않은 알림도 전체 읽기 작업을 무효화하여, 정상 방향·거리 응답을 계속 버리는 문제.
- 새 방향 알림 이후 완료된 이전 getter 응답이 최신 방향을 덮는 문제.

실제 상태/제공자가 바뀐 경우에는 이전 읽기 전체를 무효화하고, 같은 값의 반복 알림은 해당 필드의 오래된 읽기만 무효화합니다. 방향 알림에도 필드별 순서를 적용합니다. 알림이 반복되는 재현 사례와 최신 화살표 보존 검사가 통과했습니다. 순정 HUD 안내 양보, 제공자/수명주기 변경과 오래된 신호 차단은 유지합니다.

상태 파일에 실행 버전·입력 필드·읽기 성공/실패·입력 시각과 세부 해석 중단 사유를 추가했습니다. 실제 경로 좌표·목적지·주소나 원본 길안내 payload는 기록하지 않습니다. 화면과 설정 항목은1.0.4와 같습니다.

이 수정이 사용자의 차량 증상 원인까지 확정한 것은 아닙니다. 순정 HUD에서는 같은 안드로이드 안내가 표시된다는 확인이 있으므로, 이미 저장되는 cluster-redline-status.json으로 읽기/해석/렌더러 대기 중 어디에서 막히는지 확인해야 합니다. SDK나 정적 인터페이스 파일을 다시 추출할 필요는 없습니다.
