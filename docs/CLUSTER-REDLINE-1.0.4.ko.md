# 계기판 레드라인1.0.4

HUD를 이전800×240 배치로 복원했습니다. RPM 양옆에 토크·마력 게이지를 표시하고, M을 같은 위치·크기에 금속 질감으로 그립니다. HUD와 계기판 RPM 막대는 파랑→밝은 파랑→4000rpm부터 보라·분홍→설정된 적색구간 색을 공유합니다. 최대 눈금·적색 시작·크기는 각 차량 프리셋과 기존 설정을 따릅니다.

## HUD 길안내

MGU의 읽기 전용 Guidance.conclusiveDart / guidingProvider / guidanceState 신호로 방향 화살표와 제공된 거리 문자열을 표시합니다. 직진·좌우회전·유턴·분기·회전교차로를 처리합니다. 휴대폰 앱을 별도로 설치하거나 루팅하도록 요구하지 않습니다. 해당 지도 앱이 MGU에 안내를 보내고 앱의 신호 접근이 허용되어야 합니다. CarPlay/Android Auto 제공자 정의는 확인했지만 티맵·네이버 및 실차의 수신 성공은 아직 검증하지 않았습니다.

상세설정→위치/크기→HUD 길안내에서 켜짐/꺼짐, 좌우·상하 위치, 가로·세로 크기를 따로 조절합니다. 기존 HUD RPM 위젯 설정과 독립적입니다. HUD 출력을 Redline으로 선택해야 표시됩니다. 기본 안내 위치는 RPM 위젯 아래입니다.

읽을 수 있는 최신 안내가 있을 때만 합성 HUD의 경합 요청을 허용합니다. 안내가 종료되면 화살표를 지우고, 안내 중 데이터가 없거나 오래됐으면 앱 HUD를 해제하여 순정 안내를 보존합니다. 순정 팝업·외부 소유권·렌더러의 슬롯 정책은 계속 적용되며 BMW 메뉴나 렌더러 설정을 자동으로 바꾸지 않습니다.

## 설치 호환성

Guidance의 상태 getter와 Main_Instance가 없으면 해당 optional proxy를 제외합니다. 추가 방향/제공자 필드가 없으면 각각 제외하고, notifier가 없으면 읽기만 요청합니다. 이 때문에 RPM 앱 전체 설치가 실패하지 않도록 Store와 일반 설치기에서 동일하게 처리합니다.

호스트 검사와 한국어·영어 빌드로 확인합니다. 실차 동작은 아직 검증 전이며 지원되지 않는 신호를 가짜 안내로 대체하지 않습니다.
