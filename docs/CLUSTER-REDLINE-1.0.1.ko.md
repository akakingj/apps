# 계기판 레드라인 1.0.1

## HUD 길안내 전환

이전 버전은 화면 슬롯에 순정 안내가 대기하면 렌더러가 양보하는 처리에 의존했습니다. 이제 순정 내비 안내 상태를 **읽기 전용**으로 확인하여 경로 계산/안내 중에는 앱의 HUD 레이어를 해제합니다. 안내가 끝나고 최신 INACTIVE 값을 확인하면 HUD 출력을 다시 허용합니다.

인터페이스 `de.bmw.infotainment.navigation.guiding.Guidance`, 인스턴스 `Main_Instance`, 필드 `guidanceState`의 getter만 요청합니다. ACTIVE / CALCULATING_ROUTE / INACTIVE만 해석하고 숫자·불명 값을 추측하지 않습니다. 1초 간격의 소유 폴링을 쓰며 알 수 없거나 5초 이상 갱신되지 않은 값, 제공자 단절에서는 HUD를 해제합니다. 계기판은 계속 독립 동작합니다. 새 안내 이벤트가 들어오면 이전 폴링 응답이 그 상태를 덮어쓰지 못하게 합니다.

카탈로그에 이 getter가 없으면 선택적 프록시를 제외해 설치 실패를 방지하고 HUD는 순정 상태로 둡니다. 상세설정에 내비 상태 확인 불가 문구가 나옵니다. 앱이 경로를 시작/중지하거나 차량 메뉴를 변경하는 코드는 없습니다.

렌더러의 HUD 잔류 시간(기본 3초)과 다른 앱의 HUD 요청은 그대로 적용됩니다. 우리 레이어를 해제해도 다른 앱이 점유하면 순정 복귀가 보장되지 않습니다. **같은 HUD 슬롯에서 순정 길안내와 레드라인을 동시에 합성하는 기능은 여전히 미지원**입니다. 실제 차량 전환은 별도 확인이 필요합니다.

## HUD 토크·마력

RPM 숫자 양옆에 계기판 스타일의 토크·마력 미니 게이지를 추가했습니다. 800×240 원본에서 토크 x64–224, RPM x236–440, 마력 x452–612이며 위쪽 RPM 바(x64–612)를 넘지 않습니다. 최소 12픽셀 간격을 두고 값·단위·피크·눈금까지 실제 단위 환산을 적용합니다. 기어는 오른쪽에 유지합니다. 단위/데이터 없음/피크 변화의 차분 복원과 글자 범위를 검사했습니다.

## 반자율 종료 후 클러스터 복귀

정상적인 화면 반환 통지가 있으면 native 렌더러가 다시 요청하는 구조입니다. 앱에서 확인한 일시적인 오류 뒤 영구 거절 상태가 되던 경로와, 실패한 이미지가 계속 캐시되던 경로를 수정했습니다. 정확히 확인된 일시적 오류만 2/5/10초 간격, 최대 3회 다시 만들며 순정/다른 앱이 점유한 동안에는 재생성하지 않습니다. 보호 거절이나 잘못된 장면을 재시도로 우회하지 않습니다.

추가로 native 0.4.0 호스트에서 **Parked 이후 빈 슬롯 보고가 들어와도 장면 반환 콜백이 빠지면 계속 대기하는 경우**를 재현했습니다. 실차 증상과 같은 원인인지는 아직 확인되지 않았습니다. `patches/cluster-render-0.4.0-parked-recovery.patch`는 해당 누락을 보완하는 upstream 검토용 소스 패치입니다. 정확한 ID7 지도 슬롯/장면에 한정하고, 빈 슬롯을 여러 번 확인한 뒤 기존 lost/재시도 경로로 돌려보냅니다. 순정 장면을 강제로 해제하거나 HUD/guide 보호를 바꾸지 않습니다.

**이 패치는 앱 업데이트로 설치되지 않습니다.** 렌더러 소스를 수정·빌드해 적용해야 하며 실차 미검증입니다. 공식 renderer 0.4.0/0.4.1을 그대로 쓰는 차량에서 native 복귀 문제가 전부 해결됐다고 주장하지 않습니다. 자동 서비스 재시작·보호 상태 삭제도 하지 않습니다.

## 검사와 로그

- 순정 안내 상태/오래된 응답/제공자 단절, HUD만 해제, 신호 없는 차량의 설치 처리, 앱 종료 후 늦은 응답 검사를 포함합니다.
- 앱 오류 복구의 제한 재시도, 오래된 ref 무시, 신선한 RPM 조건, 순정 점유 중 재요청 억제 검사를 포함합니다.
- 실제 native SlotManager를 호스트 포트로 실행해 정상 복귀와 누락 통지 사례를 구분합니다. 하드웨어 표시 성공을 의미하지 않습니다.

정차 후 `tools/collect-cluster-redline.ps1`로 55초 동안 로그를 수집하면서 반자율 켜기→끄기 또는 길안내 시작→종료를 한 번 재현하세요. 앱 상태 JSON에 내비 판정, 출력별 복구 원인/횟수, native 상태 스냅샷도 포함합니다. SSH 개인키는 PC에서 인증에만 사용하며 보고서에 넣지 않습니다.

```powershell
powershell -ExecutionPolicy Bypass -File tools/collect-cluster-redline.ps1 -CarIp <차량IP> -IdentityFile <SSH키경로>
```

Store 소스 `jaimeen77-cmyk/apps` / main을 새로고침해 1.0.1을 선택합니다. cluster-render 최소 버전은 0.4.0입니다. SDK 포함 PC 설치본은 공개 공유하지 마세요.

네이티브 패치는 Robert Nisipeanu의 GPL-3.0-or-later 소스에 대한 수정입니다. `LICENSES/GPL-3.0-or-later.txt`와 출처 고지를 함께 유지합니다.

개발자 호스트 검사는 `python tests/native-cluster-recovery.test.py /path/to/idrive-apps`로 실행합니다. 원본 실패를 먼저 확인하고 임시 복사본에만 패치를 적용합니다. 직접 적용하려면 원본 렌더러 0.4.0 체크아웃에서 `git apply --check /path/to/patches/cluster-render-0.4.0-parked-recovery.patch`로 호환성을 확인하세요. 앱 설치 키트가 이 패치를 렌더러에 적용하지는 않습니다.
