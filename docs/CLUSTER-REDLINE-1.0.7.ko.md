# 계기판 레드라인 1.0.7

계기판 토크·마력 게이지를 확대하고 표시 글자/숫자는 확대안의 약90%로 줄였습니다. 막대 높이는26px이며 상단 M 로고와 쉬프트 알림의 위치를 교환했습니다. RPM은2500rpm에서 색이 약하게 변하기 시작해3500rpm에서 보라색, 가솔린 최대7000rpm에서 빨강이 됩니다. HUD도 같은 색상 함수를 사용합니다.

기본설정에서 다음 앱 시작 시 자동 실행할지와 현재 앱 출력의 켜기/끄기를 분리했습니다. 앱 끄기는 신호 구독·렌더러 연결을 종료하며 설정 화면은 다시 켤 수 있도록 유지합니다. 기존 자동 실행 OFF는 이전합니다. 표시 모드는 스포츠/모두 두 가지이며 모두에는 컴포트·컴포트 플러스·에코 계열 등 차량이 제공하는 유효한 주행 모드가 포함됩니다. 하위 메뉴 뒤로가기는 우측 하단에 있습니다.

1.0.6 실차 로그는 Android Auto 안내 활성과 읽기 성공을 확인했으나 maneuver_unsupported 때문에 HUD 게이지를 해제했습니다. 도로 따라가기·차로 변경·도착 안내를 원본 스키마에 맞게 추가하고 수신 종류 이름을 상태의 maneuver.kind에 남깁니다. 두 영역은 한 HUD 이미지로 합성됩니다. 원래 로그에는 종류 이름이 없으므로 이 보완으로 해당 차량의 동시 표시가 해결됐다는 실차 확인은 아직 없습니다. 처리할 수 없는 안내는 순정에 양보합니다.

한국어/영어 패키지와 Store 런타임을 갱신합니다. 렌더러 요구 버전은0.4.0 이상입니다. 엔진/변속기/차량 메뉴 제어와 렌더러 보호 설정을 변경하지 않습니다.
