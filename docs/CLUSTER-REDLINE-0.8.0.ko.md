# 계기판 레드라인 0.8.0

0.8.1은 Live Data 스타일의 공통 헤더를 사용합니다. 앱 제목 옆의 **기본설정 / 상세설정** 탭에서 설정합니다. 영어판도 같은 구조입니다.

## 기본설정

| 항목 | 선택 | 초기값 |
|---|---|---|
| 앱 자동 켜짐 | 켜짐 / 꺼짐 | 켜짐 |
| 차량 프리셋 | 가솔린 / 디젤 / eDrive (PHEV) / M | 가솔린 |
| 표시 모드 | 스포츠 모드만 / 전체 모드 | 스포츠 모드만 |
| 마력 단위 | PS / kW | PS |
| 토크 단위 | Nm / kgf·m | Nm |

자동 켜짐 아래 주황색 안내: **계기판 → 중심 표시 영역을 [꺼짐]으로 바꿔야 정상 작동합니다.**
이 안내는 설정을 대신 변경하지 않습니다. Assisted Driving View 체크박스를 변경할 필요는 없습니다.

자동 켜짐을 끄면 출력 레이어를 해제하고 신호 구독·출력 타이머를 종료합니다.
다음 MGU 부팅에도 꺼짐을 유지합니다. MainApp에는 설정을 다시 켤 수 있는 가벼운 앱 호스트가 자동 시작으로 등록돼 있습니다.

전체 모드도 정상 RPM·확인된 최신 주행 모드가 필요합니다. 시동 꺼짐, eDrive 엔진 정지,
신호 끊김, 렌더러 연결 끊김에서는 숨깁니다. 스포츠 모드만 선택하면 Sport / Sport Plus / Sport Individual에서 표시합니다.

## 상세설정

- 변속 알림 회전수: 프리셋 기본값 또는 단계별 선택. 2000 rpm 선택을 지원합니다.
- 계기판 갱신 속도: 4 / 6 / 8 / 10 / 12 / 30 / 60 fps. 실제 속도를 보장하는 값이 아닌 요청 상한입니다.
- 표시 레이어: 전면 중앙 / 지도 영역. 순정 지도·Assist 화면보다 항상 위라는 보장은 없습니다.
- 위젯 크기: 60 / 65 / 70 / 75 / 80 / 85 / 90 / 100%.

기어 앞 문자, 적색 시작 RPM, RPM 눈금 최대값, 토크·마력 눈금 최대값의 수동 메뉴는 제거했습니다.
기어 앞 문자는 수신한 D/S/M 프로그램을 사용합니다. 일반 전진 단수만 받으면 D를 붙이며,
차체 스포츠 모드만으로 S 또는 M을 추정하지 않습니다. 차량이 해당 신호를 제공하지 않으면 S/M 자동 구분에는 한계가 있습니다.

## 프리셋의 표시값

| 프리셋 | 기본 변속 알림 | 적색 시작 | RPM 최대 | 토크 눈금 | 마력 눈금 |
|---|---:|---:|---:|---:|---:|
| 가솔린 | 6500 | 6000 | 7000 | 500 Nm | 300 PS |
| 디젤 | 4200 | 5000 | 6000 | 700 Nm | 300 PS |
| eDrive (PHEV) | 6500 | 7000 | 8000 | 600 Nm | 400 PS |
| M | 7000 | 7000 | 9000 | 800 Nm | 600 PS |

차종 자동 인식이나 제조사 제원 조회가 아닌 **표시용 분류 프리셋**입니다. M과 eDrive도 모델마다 제원이 다릅니다.
330i 사용자 요청의 가솔린 7000 / 적색 6000을 유지합니다. 프리셋 변경 시 변속 알림은 해당 기본값으로 돌아갑니다.
eDrive는 엔진 RPM·엔진 토크 기반 표시입니다. 모터·시스템 합산 출력이나 순수 전기차 계기판을 의미하지 않습니다.

단위는 실제 숫자와 최고 기록값, 눈금을 함께 변환합니다. `1 PS = 0.73549875 kW`,
`1 kgf·m = 9.80665 Nm`를 사용하므로 단위만 바꿀 때 막대의 물리적 비율은 유지됩니다.
마력의 별표는 ECU 토크와 엔진 RPM으로 계산한 추정값이라는 뜻입니다.

기존 사용자의 OFF와 변속 알림·갱신 속도·표시 레이어·크기는 유지합니다.
삭제된 수동 눈금과 기어 앞 문자 설정은 저장돼 있어도 사용하지 않습니다.

## 조작과 빌드

터치·iDrive 페이지 조작을 지원하는 MGU 렌더러에서는 탭과 행을 직접 선택합니다.
렌더러가 없어도 하단 기본설정 / 상세설정 / 이전 항목 / 다음 항목 / 값 − / 값 + 버튼으로 모두 조절할 수 있습니다.
선택 목록에서는 이전/다음 또는 화면의 −/+로 이동하고 선택으로 확정합니다. 취소는 변경하지 않고 닫습니다.

```powershell
python tools/install-overlay.py C:\BMW\idrive7-apps-main --apps cluster_redline --force
cd C:\BMW\idrive7-apps-main
python kit/tools/build.py --language ko --preview-only cluster_redline
node tools/cluster-redline-settings-preview.js dist/cluster_redline preview/cluster_redline/settings
# 실제 설치 패키지는 추출한 oap-sdk가 있는 상태에서:
python kit/tools/build.py --language ko cluster_redline
```

MGU Store의 한국어·영어 항목도 같은 설정과 프리셋을 사용합니다.
[지도/Assist 전면 표시 조사](CLUSTER-OVERLAY-RESEARCH.ko.md)는 별도이며 이 업데이트가 가림 문제를 해결했다고 주장하지 않습니다.

## 확인 범위

PC에서 실제 앱 진입점, 두 탭의 하단 버튼, 설정 저장·업그레이드, 자동 켜짐 OFF/ON 정리,
뒤늦은 신호 구독의 해제, 4개 프리셋, 전체 모드·오래된 신호 숨김, 물리량 단위 변환,
변속 알림, 단위 변경 즉시 재그리기, 실제 PNG와 한국어 글꼴, 두 언어 Store 패키지를 검사합니다.
실차 조작, S/M 신호 수신, 실제 출력 fps, 지도/Assist와의 표시 순서는 PC 검사로 확인할 수 없습니다.
