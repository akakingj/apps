# 계기판 레드라인 0.4.0 수정과 지도 표시 점검

## 변속 알림과 화면

이전 버전은 메뉴에서 2000 rpm을 선택해도 가솔린·하이브리드 내부 검증이
2500 rpm 미만을 거부해서 기본 6500 rpm으로 돌아가는 버그가 있었습니다.
0.4.0은 2000 rpm을 그대로 적용하고, 도달 시 RPM 숫자와 바를 빨간색으로 표시합니다.
설정 변경은 백그라운드 표시에도 반영됩니다.

상단은 녹색·황색·적색 LED, 바는 M 삼색의 청색·보라색·적색으로 구성했습니다.
계기판에 그리던 앱 이름과 하단 변속 문구를 제거하고, 아래에 단수를 표시합니다.
단수는 `VehicleInformation.statusGearboxDrive` 또는 `DataPowerTrain2`의 실제 값만 사용합니다.
없는 신호나 구분할 수 없는 값은 `--`로 표시하며 RPM/속도 비율로 추정하지 않습니다.
단수 인터페이스는 선택 사항이므로 없는 차량도 RPM과 변속 알림은 사용할 수 있습니다.

## 지도가 앞에 나오는 경우

순정 지도와 렌더러 안의 다른 앱 지도는 서로 다른 경로입니다.

- 렌더러의 다른 콘텐츠: 스포츠 모드에서 `content`, `z=100`, `exclusive=1`을 요청합니다.
  높은 클래스의 overlay·alert는 유지합니다.
- 순정 지도: `contend=1`을 요청하며 렌더러의 **`map_take_over_stock=1`**이 필요합니다.
  앱의 z 값만 높여서는 순정 지도 슬롯 순서가 바뀌지 않습니다.

스포츠 해제·자동 표시 OFF·신호 끊김에서는 앱 레이어를 삭제합니다.
렌더러가 기존 지도를 다시 표시합니다. MGU의 지도 표시 설정이나 코딩 값을 바꾸지 않습니다.
지도 복귀와 실제 경고 우선순위는 차량에서 확인해야 합니다.

## 렌더러 버전 오류

요구 버전은 **0.3.10 이상**입니다. `0.3.1`과 `0.3.10`은 다른 버전이며,
0.3.1은 요구 버전보다 낮습니다. 확인한 개발자 소스의 현재 버전은 0.4.0입니다.
Store에서 실제 제공되는 업데이트를 확인하거나 개발자의 설치 안내를 따르세요.

이전 검사는 `/var/opt/cluster-render/current/component.json`만 보았습니다.
이제 이 경로가 없으면 `/var/opt/cluster-render/component.json`도 확인하고,
오류에 실제 발견한 버전 또는 확인한 경로를 표시합니다.
현재 설치가 오래되거나 손상되었는데 다른 경로에 새 메타데이터가 남아 있는 경우에는
새 파일로 검사를 우회하지 않습니다. 버전 검사만 낮추거나 메타데이터 숫자만 고치지 마세요.

## 차량에서 읽기 전용 점검

기존과 같이 `--language ko`로 빌드한 설치 키트에 `cluster-redline-renderer.js`가 함께 들어 있습니다.
키트를 올린 **MGU 쪽 폴더**에서 실행하세요.

```sh
node cluster-redline-renderer.js --check
```

`version`, `compatible`, `metadata`, `takeOverStock`을 확인합니다. 기본 동작은 읽기 전용입니다.
앱 상태 파일에는 `targetState`, `targetHolder`, `targetReason`, 실제 적용한 `config.shiftRpm`도 기록합니다.
`targetHolder=stock`과 `targetState=parked`는 순정 지도 뒤에 대기 중이라는 뜻입니다.

## 지도 넘겨받기가 꺼져 있을 때

지원되는 렌더러인데 `takeOverStock=false`라면, root로 다음 명령을 실행할 수 있습니다.

```sh
node cluster-redline-renderer.js --enable-map
```

이 명령은 렌더러의 로컬 설정에 `map_take_over_stock=1`을 추가하고,
원본을 `/var/opt/cluster-render/cluster-redline-map.backup.json`에 보관합니다.
실행 중인 렌더러 서비스가 있으면 다시 시작합니다. 차량의 지도 설정은 변경하지 않습니다.
이 설정은 렌더러 공통 설정이므로 다른 `contend` 앱에도 적용됩니다.
표시는 여전히 각 앱이 레이어를 요청할 때만 이루어집니다.

직전 로컬 설정으로 되돌리려면:

```sh
node cluster-redline-renderer.js --restore-map
```

설정 이후 사용자가 파일을 추가 수정했다면 자동 복원을 중지하여 그 변경을 보호합니다.
스포츠 모드를 끌 때마다 이 복원 명령을 실행할 필요는 없습니다. 앱 레이어 삭제로 지도를 돌려줍니다.

## 검증 범위

설정·색상 픽셀·단수 변환·렌더러 프로토콜·임시 폴더의 설정 복원은 PC에서 검사합니다.
**실차에서 이번 지도 우선 표시와 단수 수신은 아직 재검증하지 않았습니다.**
