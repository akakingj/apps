# 계기판 레드라인 0.8.7: 큰 글자와 터치 영역

0.8.5를 기준으로 설정 화면의 가독성과 조작 영역을 키웠습니다.

| 항목 | 이전 | 변경 |
|---|---:|---:|
| 설정 항목·선택값 글자 | 25 | 34 |
| 전체 화면 상단 탭 글자 | 18 | 28 |
| 일반 설정 행 높이 | 54 | 66 |
| 상세설정 행 높이 | 54 | 88 |
| 선택 목록의 터치 높이 | 50 | 70 |
| 선택 목록 −/+ 버튼 | 70×43 | 96×64 |
| 취소 버튼 | 250×48 | 326×64 |
| 전체 화면 하단 버튼 높이 | 48 | 80 |

수치는 앱의 논리 픽셀 기준이며 실차에서는 화면 배치에 따라 확대됩니다.
긴 주황색 안내 문구는 가로폭에 맞게 글자 크기를 조절합니다.
선택 목록은 한 화면에 네 항목을 보여주며 −/+ 또는 컨트롤러로 나머지 값을 고릅니다.

상단의 기본설정·상세설정 탭을 크게 만들고, 전체 화면 하단에는
**이전 항목 / 다음 항목 / 값 − / 값 +** 네 버튼을 같은 폭으로 배치합니다.
상단과 겹치던 하단 기본설정·상세설정 버튼은 전체 화면에서 숨깁니다.
GPU가 화면 조작을 맡지 않는 대체 표시에서는 기존 HMI 버튼을 유지합니다.

변경은 이 앱의 화면 처리에만 적용하며 공유 렌더러 서비스를 바꾸지 않습니다.
계기판 게이지와 지도 선점, 주행 모드 판단, 변속 알림, 단위 환산,
저장 설정 및 20fps 요청 상한은 0.8.5 동작을 유지합니다.

## 설치와 확인

MGU Store에서 Jam 저장소의 **main → Check now → 0.8.7 업데이트**를 진행합니다.
화면 상단의 버전은 스토어판 **v0.8.7**, 수동 한국어 빌드는 **v0.8.7-ko.1**입니다.
PC에서는 새 소스를 오버레이한 뒤 평소의 build.py / make_kit.py 명령으로 다시 빌드합니다.

스토어 빌드는 기존 SDK 없는 UI 템플릿에 현재 앱의 JavaScript를 넣습니다.
이번에는 RHMI 설정 스키마가 바뀌지 않아 기존 템플릿을 재사용하며, 실제 앱 버전은 빌드 때 갱신됩니다.

## 검증과 미리보기

실제 번들된 Display·SettingsPage를 사용해 한국어·영어의 글자 크기,
하단 네 버튼의 폭·높이·클릭, 탭 전환, 선택 목록 이동 및 취소를 검사했습니다.
GPU 전송 장치만 테스트 대역으로 바꾸며 실제 차량 신호를 보내지 않습니다.
실차의 최종 글자 크기와 터치감은 설치 후 확인해야 합니다.

```sh
node tests/cluster_redline/controls-size.test.js /path/to/dist/cluster_redline /path/to/previews
```

전체 화면 이미지는 실제 앱의 본문과 헤더·버튼을 호스트에서 합성한 미리보기입니다.
차량의 상태 아이콘은 포함하지 않습니다.
