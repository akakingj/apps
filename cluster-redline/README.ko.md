# 계기판 레드라인 · 가솔린·디젤·하이브리드 통합

한 앱에서 가솔린·디젤·하이브리드 프로필을 선택하는 **실차 검증 전 시험판 0.2.0**입니다.
기본 선택은 사용자의 2019 G20 330i에 맞춘 가솔린입니다.
MGU 앱 관리자에서 자동 시작하고, 확인된 스포츠 모드에서만
계기판 중앙 지도 영역에 큰 RPM·회전수 바·변속 알림을 표시합니다.
앱 ID는 이전과 같은 `cluster_redline`이므로 차량별 앱을 따로 설치하지 않습니다.

## 요청한 동작

| 상황 | 동작 |
|---|---|
| MGU 부팅 직후 | 앱은 백그라운드에서 시작. 계기판 표시 OFF. 슬롯을 예약하지 않음. |
| Comfort / Eco / Adaptive | 표시 OFF. 순정 화면 유지. |
| Sport / Sport+ / Sport Individual 확인 | 최신 RPM 신호와 1초 확인 시간을 만족하면 중앙 레드라인 표시 요청. |
| 프로필의 변속 알림 회전수 도달 | 변속 표시등 전체 점등과 `변속 시점` 안내. 설정값 변경 가능. |
| 스포츠 모드 해제 | 앱의 계기판 레이어를 삭제. 순정 화면 복귀는 렌더러가 처리. |
| 모드·RPM 신호 없음/오래됨 | 표시 OFF. 데모 값으로 대체하지 않음. |
| 렌더러 연결 끊김 | 레이어와 신호 확인 상태를 초기화. 새 신호 확인 후 표시. |
| 자동 표시 설정 OFF | 스포츠 모드에서도 표시하지 않음. |

앱을 항상 열어둘 필요가 없습니다. 설정 앱 화면을 닫아도 표시 조건 확인은 계속됩니다.
`스포츠 모드 자동 표시` 설정 자체는 기본 ON이며, **화면의 기본 상태가 OFF**입니다.
설정 화면을 부팅 때 자동으로 열도록 만들지는 않았습니다.
기어레버의 D/S 선택이 아닌 차량의 주행 모드 SPORT를 기준으로 합니다.

## 엔진 프로필

앱 설정의 **엔진 프로필**에서 선택하세요. 프로필을 바꾸면 알림·레드라인·눈금의
수동값이 `프로필 기본값`으로 돌아가며, 최신 차량 신호를 다시 확인한 뒤 표시합니다.

| 프로필 | 변속 알림 | 레드라인 표시 | 눈금 최대 | 엔진 정지 시 |
|---|---:|---:|---:|---|
| 가솔린 | 6500 rpm | 7000 rpm | 8000 rpm | 숨김 |
| 디젤 | 4200 rpm | 5000 rpm | 6000 rpm | 숨김 |
| 하이브리드 | 6500 rpm | 7000 rpm | 8000 rpm | 정상적인 엔진 정지로 처리하고 숨김 |

이는 모든 차종에 공통으로 검증된 엔진 한계가 아니라 초기 **표시·알림 프리셋**입니다.
차량별 회전수 범위에 맞게 조정하세요. 디젤의 수동 알림 값은 2000~5000 rpm,
레드라인 표시는 3000~5500 rpm, 눈금은 4000~7000 rpm 범위를 받습니다.
범위를 벗어난 설정은 해당 프로필 기본값을 사용하며, 실제 적용값은 상태 화면에서 확인합니다.

하이브리드는 330e·530e 같은 가솔린 기반 플러그인 하이브리드를 대상으로 한 프로필입니다.
스포츠 모드이면서 엔진이 작동할 때 RPM을 표시합니다. 엔진이 정지하면 표시를 해제하고,
엔진 재시동 후 최신 RPM이 들어오면 다시 표시합니다.
RPM 0만으로 전기 구동·주차·회생 여부를 구분하지 않습니다.
전기 출력·회생 kW·배터리 SOC 표시나 순수 전기차용 화면은 포함하지 않습니다.

프로필은 직접 선택하는 방식이며 자동 엔진 종류 판별은 하지 않습니다.
0.1.x에서 업그레이드하면 기존 가솔린 수동 설정을 유지합니다.
프로필을 실제로 변경할 때만 세 회전수 설정을 초기화합니다.

## 필요한 환경

- MGU / iDrive 7, `cluster-render`의 **ID7 `map:1088x480` 대상** 지원.
- `cluster-render` **0.3.10 이상**. 이미 설치했어도 버전 확인이 필요합니다.
- `mgu-deploy` **0.7.17 이상**에서 `mguAppStartType: autostart`를 지원하는 설치 경로.
- 차량 SOME/IP 카탈로그에 다음 읽기용 필드와 getter가 존재해야 합니다.
  - `de.bmw.infotainment.vehicle.CDS.statusEngineSpeed2`
  - `de.bmw.infotainment.drivingexcitement.FES.statusFESVehicleDynamicSwitchHMI`

일반 `build.py`로 만든 앱을 수동 시작 방식으로 설치하는 기존 설치 도구는
자동 시작 마커를 무시할 수 있습니다. **아래 사전 점검과 `mgu-deploy` 설치를 사용하세요.**
제어기 펌웨어·코딩을 바꾸거나 별도의 root 자동 시작 서비스를 설치하지 않습니다.

## 받는 파일

- `cluster-redline-universal-install.zip`: 소유 차량에서 제공한 SDK로 빌드한 개인 설치용 패키지.
  SDK가 포함되므로 공개 GitHub 배포용 소스와 구분하세요.
- `cluster-redline-source.zip`: 앱 소스·검사·빌드 도구. SDK와 설치용 바이너리 미포함.
- `preview/`: 실제 앱 코드로 만든 중앙 영역 미리보기. 숫자는 데모 수치입니다.

## 차량에서 사전 점검과 설치

설치 ZIP을 풀면 다음 파일을 함께 사용합니다.

```text
cluster_redline@0.2.0-ko.1.mgu
preflight.js
install-on-mgu.sh
release.json
```

기존 SSH/SCP 접속 방법으로 이 파일들을 MGU의
`/var/opt/cluster-redline-kit/`에 복사하세요. 이후 **MGU 쪽 터미널**에서 실행합니다.

먼저 읽기 전용 점검:

```sh
cd /var/opt/cluster-redline-kit
sh install-on-mgu.sh check
```

모든 항목이 통과해야 설치할 수 있습니다. `mgu-deploy`나 `cluster-render` 버전이
부족하면 Store에서 해당 도구를 업데이트하고 점검을 다시 실행하세요.
필수 차량 신호 getter가 없으면 해당 펌웨어는 이 패키지로 자동 표시할 수 없습니다.

설치 도구는 `release.json`에 지정된 패키지를 선택하고 SHA-256을 확인하므로,
같은 폴더에 이전 버전 파일이 있어도 최신 묶음의 지정 파일만 사용합니다.

실제 설치는 root로 실행합니다.

```sh
sh install-on-mgu.sh install
```

이는 `mgu-deploy`의 표준 검사·설치 경로를 사용합니다. 설치 도구가 표시하는
재시작 안내를 따르고, 정상적인 MGU 재시작 후 앱의 자동 시작을 확인하세요.
저장소에 앱을 올리는 것만으로 차량에 설치되는 것은 아닙니다.

## 설정 화면

iDrive의 `계기판레드라인` 앱은 서비스 상태와 다음 설정을 보여줍니다.

- 스포츠 모드 자동 표시: 기본 ON.
- 엔진 프로필: **가솔린 / 디젤 / 하이브리드**. 기본 가솔린.
- 변속 알림 회전수·레드라인·눈금: 기본 **프로필 기본값**.
- `프로필 기본값`의 내부 값 0은 회전수 0이 아니라 위 표의 프리셋 사용을 뜻합니다.
- 계기판 갱신 속도: 기본 **8 fps**, 최대 12 fps.

이 숫자는 표시·알림 설정값이며 차량의 엔진 제한이나 변속기 제어값이 아닙니다.
표시가 불필요하면 `스포츠 모드 자동 표시`를 OFF로 바꾸세요.

상태의 `requested`는 앱이 보이도록 요청했다는 뜻이며,
실제 표시 여부는 `layerState`의 `shown`, `waiting`, `suspended` 등으로 확인합니다.
계기판 모드나 다른 콘텐츠가 슬롯을 보유하면 요청해도 즉시 보이지 않을 수 있습니다.

## 화면과 우선순위

대상은 **중앙 지도 영역(`map`) 하나**로 고정했습니다.
전체 계기판(`panel`)이나 HUD를 대체하는 코드 경로는 없습니다.

- 부팅·일반 모드에서는 레이어를 만들지 않으며 `prewarm`도 사용하지 않습니다.
- 표시할 때는 낮은 콘텐츠 우선순위(`z=-100`)를 사용하며 독점 레이어로 만들지 않습니다.
- `guide_hold=0`으로 순정 길안내 패널을 숨기지 않도록 요청합니다.
- `contend=1`은 스포츠 표시가 필요할 때 중앙 지도 슬롯을 순정 지도에서 넘겨받도록 요청합니다.
- 표시 중에는 중앙의 순정 지도가 이 위젯으로 교체될 수 있습니다.

순정 속도계·회전계 영역을 직접 덮지 않습니다. 다만 경고·길안내·다른 앱과의 실제
우선순위와 복귀 동작은 차량·펌웨어별로 실차 확인이 필요합니다.

## 신호와 고장 시 동작

- RPM: `actualValueRPMEngineCrankshaft × 0.25`.
- 주행 모드: `actualValueModeDrivingExperience`.
- 확인하는 스포츠 값: `SPORT_DYNAMIC`, `SPORT_EXPERT`, `SPORT_INDIVIDUAL`, 숫자 1·2·3.
- 모드 getter는 1초마다 다시 읽습니다. 3.5초 넘게 갱신되지 않으면 숨깁니다.
- RPM이 1.8초 넘게 갱신되지 않거나 값이 유효하지 않으면 숨깁니다.
- 엔진 정지(100 rpm 미만), 알 수 없는 모드, 렌더러 거부·다른 대상 크기에서는 숨깁니다.
- 렌더러 재연결 시 예전 표시를 자동 재생하지 않고 새로운 모드·RPM을 기다립니다.

차량 신호에는 쓰기 API를 사용하지 않습니다. 스포츠 모드를 켜거나 변속을 지시하는 기능도 없습니다.

## PC에서 소스 빌드

한국어 지원이 있는 원본 `idrive7-apps` 프로젝트와 Python 3, Node.js가 필요합니다.
원본 프로젝트 파일은 변경하지 않고 이 앱만 별도 `dist` 폴더에 빌드합니다.

```powershell
python tools/build.py --project "C:\작업\idrive7-apps" --preview-only
node tools/preview.js
```

`preview/index.html`을 열면 기본 표시 OFF, 일반 스포츠 화면, 변속 알림 화면을 비교할 수 있습니다.
PC 미리보기에서는 실제 계기판 소켓에 연결하지 않습니다.

설치용 빌드는 소유 차량에서 추출한 SDK 경로를 추가합니다.

```powershell
python tools/build.py --project "C:\작업\idrive7-apps" --sdk "C:\작업\idrive7-apps\oap-sdk"
```

결과는 `dist/cluster_redline@0.2.0-ko.1.mgu`와 npm 형식 `.tgz`입니다.
빌드 도구가 두 형식 모두에 `mguAppStartType=autostart`와 `mguLocalOnly=true`를 기록합니다.
원본 `build.py`만 직접 사용하면 이 추가 메타데이터가 빠지므로 이 저장소의 빌드 도구를 사용하세요.

`node tests/profile-settings.test.js 원본프로젝트경로`를 실행하세요.
